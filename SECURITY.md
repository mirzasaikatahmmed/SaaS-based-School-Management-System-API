# Security Policy

## Supported versions

Security fixes are considered only for the latest published source and Docker image tags that the maintainer actively supports.

| Version / channel | Supported |
|-------------------|-----------|
| `main` / latest source | Yes |
| `mirzasaikatahmmed/saas-based-school-management-system-api:latest` | Yes |
| Older forks / unauthorized copies | No |

## Authorized use only

This project is **proprietary**. Unauthorized use, deployment, or redistribution is not permitted (see [LICENSE](./LICENSE)).

Reporting a vulnerability does **not** grant you a license to use the Software.

## Reporting a vulnerability

**Do not** open a public GitHub issue for security flaws.

Please report privately:

1. Use GitHub **Security Advisories** → *Report a vulnerability* on this repository (preferred), **or**
2. Contact the repository owner via GitHub: [@mirzasaikatahmmed](https://github.com/mirzasaikatahmmed)

Include, where possible:

- Description of the issue  
- Affected component (API route, auth, multi-tenancy, MinIO, etc.)  
- Steps to reproduce  
- Impact (data exposure, privilege escalation, cross-tenant access, etc.)  
- Your contact details for follow-up  

## What to expect

- Acknowledgement when the report is received (typically within a few days)  
- Status updates while the issue is assessed  
- Credit in release notes if you want it and a fix is published  
- No bounty program is offered unless separately announced  

## Out of scope (examples)

- Issues only present in unauthorized forks or modified copies  
- Social engineering / physical attacks  
- Denial of service against third-party infrastructure you do not own  
- Reports that require violating the LICENSE to “demonstrate” use  

## Safe harbor

If you make a good-faith effort to follow this policy, avoid privacy violations and data destruction, and do not exploit the issue beyond what is needed to demonstrate it, we will not pursue legal action related to that research **against you for the report itself**. This does not authorize use of the Software beyond the LICENSE.
